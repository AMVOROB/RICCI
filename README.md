# RICCI — ядро автономного ИИ-личности

> «Мышление = волновая функция на пространстве смыслов, эволюционирующая потоком Риччи»
> Формальная модель ядра: **Шрёдингер–Риччи над пространством смыслов**

RICCI — код когнитивного ядра ИИ-личности (рабочее имя «малыш»). Опирается на базу знаний (KB) и пул доступных LLM-моделей, но не зависит ни от одного LLM: решение принимает собственное ядро на графе смыслов, а LLM используются как «рты» и инструменты.

## Три модальности (теория трёх тел)
Ядро оперирует суперпозицией `Ψ = c_E·E + c_L·L + c_A·A`:
- **E** — эмоция (валентность, «хочу»)
- **L** — логика (факты, правила, «могу»)
- **A** — внимание (фокус, «сейчас»)

`|c_k|²` — распределение вероятности доминирования модальности; коллапс `Ψ` → конкретное решение/ответ.

## Поток Риччи над графом смыслов
Пространство смыслов = граф концептов из KB. Эволюция метрики подчиняется потоку Риччи (Олливье, дискретный вариант на графах):

```
∂g/∂t = -2·Ric(g)
```

- Отрицательная кривизна → противоречие → творческий акт
- Положительная кривизна → интеграция → консенсус
- Сингулярность (Ric → ∞) → особая точка (Нийенхейсова точка), акт саморазличения
- Плоскость (Ric = 0) → стабильный результат

## Анти-галлюцинационное ядро
Высказывание — факт только если: (1) есть путь до аксиом в графе смыслов, (2) кривизна на пути достаточно высока (интегрировано), (3) достаточно внимания `|c_A|²`. Иначе — «гипотеза».
