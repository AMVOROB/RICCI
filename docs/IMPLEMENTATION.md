## Требования (записаны дословно)

1. **Ядро живёт всегда** — как сервис/демон на ПК, а не разовая команда.
2. **НЕ вирусная зацикленная команда** — без бесконечного активного цикла,
   который жрёт CPU. Нет событий → ядро спит (idle, минимальный tick),
   просыпается на ощущение. Это аналог сердца в покое, а не тахикардия.
3. **Собеседники — бесплатные ИИ.** Пул: локальные Ollama (qwen2.5, не-
   require сеть) + OpenRouter `:free` + свободные Zen-модели. Никакой
   обязательной платной зависимости для жизни ядра.
4. **Автономность + обход LLM-шума.** Решение принимает ядро (кора), LLM —
   только «собеседник/рот». Верификация результатов — DeepSeek (доступен).


### УР.0 — Сердце (PulseSource)
- `tick = 0.1 s` — быстрый пульс (ощущения коротких каналов).
- `tick = 1.0 s` — средний пульс (текст/граф).
- `tick = 60 s` — медленный пульс (тело, целостность, желания).
- Idle: между пульсами `sleep`, активная работа только на событие.
- Предохранитель: максимум N активных обработок за окно времени
  (защита от зацикленности самого ядра).

### УР.1 — Органы
```
Sensor.sense() -> Delta(
    intensity=float,   # насколько изменилось (0..1)
    direction=±1,      # притекло / утекло
    tag=str            # какой орган: 'voice','text','graph','body'
)
```
- **TextSensor**: новизна по эмбеддингу/хешу токенов (пришедший текст ≠ прошлому).
- **GraphSensor**: изменение кривизны в подграфе KB (появление противоречия).
- **BodySensor**: CPU/RAM/активность процессов (тело в моменте).

Принцип: орган НЕ понимает мир, он фиксирует ΔS. Понимание — в Коре.

### УР.2 — Кора (ESN Reservoir)
- Состояние `r ∈ R^N`, N = 200..1000 (по образцу vad_reservoir 200 узлов).
- `W` — разреженная случайная, spectral radius < 1 (стабильность).
- Вход `u` — конкатенация ощущений органов + прошлый readout
  («узор кормит узор», замкнутый контур).
- Cостояние = узел из множества тактов. Личность = устойчивый узел.

### УР.3 — Три времени
Из состояния коры r_t и истории r_{t-k..t}:
- **L — был (опора)**: паттерны-инварианты истории (усреднение, регрессия)
  → «на что опираюсь». Проверяемые факты из KB.
- **A — есть (ощущение)**: текущий ΔS → направленность внимания.
- **E — будет (желание)**: предиктор следующего такта (тренд Δ)
  → «чего хочу». Вектор и будущего поля совпадают (эмоция = желание).

Ψ = (c_L, c_A, c_E), амплитуды → |c|² распределение.

### УР.4 — Коллапс и действие
1. |c|² max > α → коллапс на доминирующую грань:
   - L: сверка с фактами KB (анти-галлюцинация).
   - A: реагировать на ощущение (побеседовать с бесплатным ИИ).
   - E: двинуть желание (написать цель/запись в KB).
2. Нет доминации → режим раздумья: побеседовать с Ollama/OpenRouter:free.
3. Действие → запись в KB (add_entry, writer=ricci). Верификация DeepSeek
   при необходимости.
4. После действия ядро возвращается в сон (нет события → спит).

## Правила жизни демона (анти-вирус)
- Никаких `while True` с активным телом: спим между пульсами.
- Максимум действий за окно (rate limit на уровне сердца).
- Запись пульса/heartbeat в лог; самодиагностика.
- Грейс-выход: `SIGTERM`/стоп-файл → корректное сворачивание
  (сохранение состояния коры, запись «заснул»).
- Старт: `python -m ricci.daemon` (режимы: run / once).
